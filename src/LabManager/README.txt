個人カルテ（LabManager）

テレビ画面の在席表示はそのままです。ログインは個人カルテを開くときだけです。

開き方
  1. LabManager を起動する
  2. 右画面の MENU を押す
  3. 「18:個人カルテ」を押す
  4. 学籍番号とパスワードを入れる

パスワードは LabPortal と同じ lab_user です。まだ行が無い人は、personal_info にあれば初期パスワード lab2026 で入れます。
教員は学籍番号に teacher と入れ、開いたあと見る学生の学籍番号を選びます。
メールアドレスでは入れません。

個人カルテに出るもの
  出席（touch_log / chip_list）
  日直（duty_schedule）本日まで
  進捗（progress_log）研究の途中経過。いまは仮データ
  文献（references_list）その人が読んだ論文・資料。いまは仮データ
  その学籍番号の記録だけです。無い項目は「未登録」と、参照したテーブル名が出ます。
  カレンダーと日誌は出しません。研究室全体の一覧は「15:まとめページ」です。

登録と編集は今までどおり各メニューです。個人カルテは参照だけです。
