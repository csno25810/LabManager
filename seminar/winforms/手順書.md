# 手順書: 一覧メモを作る

今日作るのは、入力した文字を一覧に追加し、選んだ行を下に表示する窓です。技術の名前は Windows Forms です。研究室のテレビ画面も、同じようにフォームへ部品を置いて作っています。今日は研究室のデータベースには繋ぎません。

完成すると、こう動きます。

```
┌ 一覧メモ ──────────────────────┐
│ [ ここに文字を入れる      ] [追加] │
│ ┌────────────────────────────┐ │
│ │ ゼミ                        │ │
│ │ 発表                        │ │
│ └────────────────────────────┘ │
│ ゼミ                            │
└────────────────────────────────┘
```

上の枠に「ゼミ」と入れて「追加」を押すと、中央の一覧に出ます。その行をクリックすると、一番下の文字が「ゼミ」になります。

部品は次の順で置いてください。順を変えると、プログラムが参照する名前がずれます。

1. TextBox（名前は `textBox1` になる）
2. Button（名前は `button1` になる）
3. ListBox（名前は `listBox1` になる）
4. Label（名前は `label1` になる）

## 手順 1. プロジェクトを作る

1. Visual Studio 2022 を開く。
2. 「新しいプロジェクトの作成」を押す。
3. 検索欄に `Windows フォーム` と入れる。
4. 言語が C# の「Windows フォーム アプリ (.NET Framework)」を選び、「次へ」。
5. プロジェクト名を `ListMemo` にする。
6. フレームワークで「.NET Framework 4.8」を選び、「作成」。

中央に空の窓（フォーム）が出れば、この手順は完了です。

一覧に「Windows フォーム アプリ (.NET Framework)」が無いときは、C# の「Windows フォーム アプリ」を選んでください。あとの手順は同じです。どちらも無いときは手を挙げてください。開始用のプロジェクトを渡します。

## 手順 2. 部品を置く

左の「ツールボックス」が無いときは、メニューの「表示」→「ツールボックス」を開きます。

「コモン コントロール」から、上の順でフォームへドラッグします。

置いたあと、その部品をクリックし、右下の「プロパティ」で次を設定します。プロパティが無いときは F4 を押します。フォーム自体のタイトルを変えるときは、フォームの何も無いところをクリックしてから `Text` を変えます。部品を選んだままだと、その部品の文字が変わります。

| クリックするもの | プロパティ | 値 |
|---|---|---|
| ボタン | Text | 追加 |
| ラベル | Text | 選ぶと、ここに表示されます |
| ラベル | AutoSize | False |
| フォームの空き | Text | 一覧メモ |

名前はプロパティの先頭にある `(Name)` で確認します。`textBox1`、`button1`、`listBox1`、`label1` になっていなければ、`(Name)` をその文字列に直してください。

入力枠は上、ボタンはその右、一覧は中央、ラベルは一番下、になるよう広げてください。見た目が多少ずれていても、この先の動作には影響しません。

## 手順 3. 追加ボタン

ボタンをダブルクリックします。`Form1.cs` が開き、`button1_Click` というメソッドができます。中を次のとおりにします。メソッドの外側には書かないでください。

```csharp
private void button1_Click(object sender, EventArgs e)
{
    string text = textBox1.Text.Trim();
    if (text.Length == 0)
    {
        return;
    }

    listBox1.Items.Add(text);
    textBox1.Clear();
    textBox1.Focus();
}
```

各行の意味は次のとおりです。

- `Trim` は、前後の空白を外します。
- 文字数が 0 のときは `return` で処理を終え、一覧には足しません。
- `Items.Add` が一覧の末尾に行を足します。
- `Clear` が入力枠を空にし、`Focus` が次の入力のためにカーソルを戻します。

メニューの「ファイル」→「すべて保存」を押します。

## 手順 4. 選んだ行を下に出す

フォームのデザイン画面に戻ります。タブの `Form1.cs [デザイン]` をクリックするか、ソリューション エクスプローラーで `Form1.cs` をダブルクリックします。

一覧（ListBox）をダブルクリックします。`listBox1_SelectedIndexChanged` ができたところへ、次を書きます。

```csharp
private void listBox1_SelectedIndexChanged(object sender, EventArgs e)
{
    if (listBox1.SelectedItem == null)
    {
        return;
    }

    label1.Text = listBox1.SelectedItem.ToString();
}
```

`SelectedItem` は、今選ばれている行です。何も選ばれていなければ何もしません。選ばれていれば、その文字を下のラベルへ入れます。

ダブルクリックでメソッドが作れないときは、一覧をクリックした状態でプロパティ窓の雷のアイコンを押し、`SelectedIndexChanged` をダブルクリックしてください。

## 手順 5. 動かす

F5 を押します。窓が出たら、次の順に操作します。

1. `ゼミ` と入れて「追加」を押す。一覧に「ゼミ」が出て、入力枠が空になる。
2. `発表` と入れて「追加」を押す。一覧が 2 行になる。
3. 何も入れずに「追加」を押す。行は増えない。
4. 「ゼミ」の行をクリックする。下の文字が「ゼミ」になる。
5. 「発表」の行をクリックする。下の文字が「発表」になる。

ここまでできれば完成です。止めるときは、実行中の窓を閉じるか、Shift+F5 を押します。

入れる言葉は自分で決めて構いません。上の 5 つと同じ動きになれば成功です。

## 余力があるとき

ボタンをもう 1 つ置き、`Text` を「削除」にします。後から置いたボタンの名前は `button2` になります。プロパティで確認してください。ダブルクリックして、次を書きます。

```csharp
private void button2_Click(object sender, EventArgs e)
{
    if (listBox1.SelectedItem == null)
    {
        return;
    }

    listBox1.Items.Remove(listBox1.SelectedItem);
    label1.Text = "選ぶと、ここに表示されます";
}
```

一覧で行を選んで「削除」を押すと、その行が消え、下の文字が最初の文に戻ります。

## つまずいたとき

| 症状 | 見ること |
|---|---|
| ツールボックスが無い | 「表示」→「ツールボックス」 |
| プロパティが無い | 部品をクリックして F4 |
| フォームのタイトルが変わらない | 部品の `Text` を変えている。フォームの空きをクリックしてから `Text` を変える |
| 赤線が `textBox1` などに付く | プロパティの `(Name)` が手順の名前と違う |
| `button1_Click` が無い | ボタンをダブルクリックする。コードはクラスの `{ }` の中に書く |
| F5 でビルドエラー | 手順 3 と 4 の波括弧が、手順書と対になっているか見る |
| テンプレートが無い | 手を挙げる。開始用プロジェクトを開いて手順 2 から続ける |
| .NET Framework 4.8 を選べない | 「Windows フォーム アプリ」の方で作成する。手順 2 以降は同じ |
