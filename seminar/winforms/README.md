# Windows Forms 体験授業

研究室ゼミで、Windows Forms の窓を1枚作る回の一式です。テレビアプリ LabManager と同じ種類のプロジェクトで、文字を一覧に追加し、選んだ行を下に表示するところまでやります。研究室のデータベースには繋ぎません。

想定時間は 45 分です。25 分しか無いときは、下の「短い回」に切り替えてください。

## ファイル

| ファイル | 誰が使うか | いつ渡すか |
|---|---|---|
| `事前連絡.txt` | 参加者 | 前日まで |
| `手順書.md` | 参加者 | 前日、または当日の開始時 |
| `原稿.md` | 発表者 | 渡さない。読み上げ用 |
| `download/ListMemo_完成.zip` | 発表者 | 渡さない。最初の見本と、終わったあとの答え合わせ |
| `download/ListMemo_開始用.zip` | 遅れた人だけ | プロジェクト作成で止まった人にその場で渡す |

完成品を先に配ると、写すだけで終わります。見本は発表者の PC だけで動かしてください。

## 前日にやること

1. `事前連絡.txt` を送る。
2. 自分の Windows PC で `download/ListMemo_完成.zip` を解凍し、`ListMemo.sln` を Visual Studio で開く。F5 で窓が出ることを確認する。
3. 上の枠に文字を入れて「追加」を押し、一覧の行をクリックして下の文字が変わることを確認する。
4. `download/ListMemo_開始用.zip` も一度開き、空の窓が出ることを確認する。
5. 手順書の手順 1 から 5 を、完成品とは別の場所で新規プロジェクトとして一度通す。当日にメニューの名前で迷わなくするためです。

この教材を作った環境では Visual Studio を起動できないので、上記の確認は発表者の Windows PC で行ってください。

## 当日の机の上

- 発表者の PC（完成品を開いた状態で待機。実行はまだしない）
- 手順書を投影できると、コードを口頭で一字ずつ読まなくて済みます
- 開始用 zip をすぐ渡せる場所（USB か、その場で開ける共有フォルダ）

## 45 分の流れ

| 時刻 | 内容 | 原稿の見出し |
|---|---|---|
| 0:00 | 今日作るものの説明 | 1. 導入 |
| 0:04 | 完成品を操作して見せる | 2. 見本 |
| 0:07 | テレビ画面との対応 | 3. 研究との対応 |
| 0:11 | 手順 1 プロジェクト作成 | 4. 手順 1 |
| 0:19 | 手順 2 部品を置く | 5. 手順 2 |
| 0:29 | 手順 3 追加ボタン | 6. 手順 3 |
| 0:37 | 手順 4 行を選ぶ | 7. 手順 4 |
| 0:43 | 手順 5 の確認と締め | 8. 確認と締め |

各手順の終了条件は原稿に書いてあります。全員が揃うのを待たず、部屋の半数ができたら次へ進み、遅れた人には開始用を渡すか、近くの完成した人に画面を見せてもらってください。

## 短い回（25 分）

前日の連絡に、次の一文を足します。

> 当日は `ListMemo_開始用.zip` を解凍し、中の `ListMemo.sln` を Visual Studio で開いておいてください。

当日は手順 1 を飛ばし、手順 2 から始めます。研究との対応は「テレビの一覧も、フォームに置いた部品です」の一文にします。

## 成功の定義

各自の PC で、次の 3 つができていれば完成です。

1. 文字を入れて「追加」を押すと、一覧にその行が出て、入力枠が空になる。
2. 空のまま「追加」を押しても、行が増えない。
3. 一覧の行をクリックすると、下の文字がその行になる。
