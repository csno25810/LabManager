========================================
  研究室テレビPC用 DB 情報取得ツール
========================================

【目的】
  LabManager を研究室に入れる前に、
  felica データベースの中身（テーブル・列）を調べる。

【持ち物】
  USB メモリにこのフォルダ一式を入れる:
    lab_phase0.py
    lab_phase0.bat
    README.txt

【テレビPCでの手順】（5分）

  1. USB を挿す

  2. このフォルダをデスクトップにコピー
     （USB から直接実行しても OK）

  3. lab_phase0.bat をダブルクリック

  4. 黒い画面に「接続成功」「完了しました」と出る

  5. 同じフォルダに db_info.txt ができる
     → これを USB に入れて持ち帰る

【うまくいかないとき】

  ■ 「mysql.connector が見つかりません」
    → デスクトップの「その他\タッチする.py」を
      ダブルクリックして動くか確認。
      動くなら同じ PC なので、管理者に Python 環境を確認。

  ■ 「接続に失敗しました」
    → MySQL が止まっている可能性。
      研究室の先輩・管理者に MySQL サービス起動を依頼。
    → C:\MyReader\SQLReader.ini があるか確認。

  ■ mysql.exe は不要
    → このツールは Python だけで動きます。

【持ち帰ったあと】
  db_info.txt を自宅PCの LabManager プロジェクトに渡す。
  足りないテーブル・列だけ追加する SQL を作成する。

【任意: DB バックアップ】
  db_info.txt の末尾に mysqldump の実行例が書かれます。
  時間があれば backup_felica.sql も作って持ち帰ると安全です。
